# netsh-bot

A Discord bot for community attendance, rules, roles, and news commands.

## Requirements

- Node.js 18 or newer
- A Discord application and bot token

## Setup

1. Install dependencies:

   ```bash
   npm install
   ```

2. Copy `.env.example` to `.env`.
3. Replace every placeholder in `.env` with your Discord credentials and server IDs.
4. Start the bot:

   ```bash
   npm start
   ```

## Security

Never commit or share your `.env` file. It contains the bot token and Discord server configuration.
